先看这里，再安装

拾光存档 v__SHIGUANG_VERSION__ 朋友测试版 · Windows / Mac · Chrome / Edge

1解压先把整个 ZIP 解压出来。
2固定位置把扩展文件夹放好，不再移动。
3加载在扩展管理页选择正确文件夹。
4固定图标让“拾光存档”一直显示在工具栏。

最重要的一件事：安装时请选择旁边的 shiguang-archive-extension 文件夹。安装后不要移动或删除它，否则浏览器会找不到扩展。

选择你正在使用的浏览器

Windows 和 Mac 的浏览器步骤基本相同，页面下方补充了各自的文件夹提示。

chrome://extensions/
  1. 打开扩展管理页复制上面的地址，粘贴到 Chrome 地址栏，再按回车。
  2. 打开“开发者模式”在扩展管理页右上角开启这个开关。测试版安装必须开启。
  3. 点击“加载已解压的扩展程序”不要选择 ZIP，也不要选择这张导航页。
  4. 选择 shiguang-archive-extension 文件夹打开后应当能直接看到 manifest.json。如果还要再点进一层，请选择更里面那一层。
  5. 固定“拾光存档”图标点击 Chrome 右上角的拼图图标，在“拾光存档”旁点击固定图标。
Windows：请先点“全部解压缩”，建议把扩展文件夹放到“文档”中。
Mac：双击 ZIP 解压，建议把扩展文件夹放到“文稿”中。
edge://extensions/
  1. 打开扩展管理页复制上面的地址，粘贴到 Edge 地址栏，再按回车。
  2. 打开“开发人员模式”在扩展管理页左侧或页面下方开启这个开关。
  3. 点击“加载解压缩的扩展”不要选择 ZIP，也不要选择这张导航页。
  4. 选择 shiguang-archive-extension 文件夹打开后应当能直接看到 manifest.json。如果还要再点进一层，请选择更里面那一层。
  5. 让“拾光存档”显示在工具栏打开 Edge 右上角的“扩展”菜单，在“拾光存档”旁选择“在工具栏中显示”。
Windows：请先点“全部解压缩”，建议把扩展文件夹放到“文档”中。
Mac：双击 ZIP 解压，建议把扩展文件夹放到“文稿”中。

安装完成后，这样保存文章

以后每篇文章都是同样的操作，不需要重复安装。

1

打开公开文章

用刚才安装扩展的 Chrome 或 Edge，打开一篇可以正常阅读的公众号文章。

2

点击“拾光存档”

在工具栏点击扩展图标，确认标题后选择“保存当前文章”。

3

直接打开结果

显示保存完成后，点击“打开已保存文章”；文件也会保留在浏览器下载文件夹中。

第一次出现“允许读取微信图片”怎么办？

这是浏览器自己的授权提示，只在你主动保存时用于读取文章里的微信图片。正文整理和文件生成都在本机完成，不上传给开发者，也不调用 AI 模型。

选择允许文章图片可以一起放进离线文件，建议这样选。
选择拒绝仍会保存正文，图片位置显示本地提示；以后可以重新授权。

更新、卸载与常见问题

保存过的 HTML 是普通本地文件，更新或卸载扩展不会自动删除它们。

收到新版本，怎么更新？
  1. 先解压新版本，并把新的扩展文件夹放到固定位置。
  2. 在扩展管理页移除旧版“拾光存档”。
  3. 按本页步骤加载新文件夹，并重新固定图标。
  4. 确认新版能打开后，再删除旧的扩展文件夹。
怎么卸载？

回到 Chrome 或 Edge 的扩展管理页，在“拾光存档”卡片中点击“移除”。以前保存的文章不会被自动删除。

提示“清单文件缺失”怎么办？

通常是选错了文件夹。请重新选择 shiguang-archive-extension，并确认打开后能直接看到 manifest.json。

为什么显示“部分保存”？

音视频、小程序、互动组件、超限图片或暂时无法读取的图片不能完整离线化。正文仍会保存，结果页会说明未保留的内容。

浏览器为什么提示开发者模式？

因为朋友测试版还没有上架浏览器商店。请只使用你从可信原分享渠道收到的安装包。

遇到问题，一键整理反馈

打开“拾光存档”，点击“复制安全反馈”，再把复制的文字发回原分享渠道。它只整理版本、浏览器和错误编号等排查信息，不会自动附带文章正文、链接、Cookie 或账号信息。
